# Amperverser DnD Table

Виртуальный стол для D&D 5e в духе Owlbear Rodeo: кампании, приглашения по ссылке, роли мастер/игрок, сцены с картами и токенами, туман войны, линейка, рисование, чат с кубиками, инициатива, листы персонажей и справочник (расы, классы, предыстории, предметы, заклинания, бестиарий, черты, состояния) на русском.

**Стек:** Python 3.10+ · FastAPI · SQLAlchemy (async) · **MySQL** (или SQLite для локального запуска) · WebSocket · ванильный JS/Canvas (без сборки).

> Почему Python, а не Rust: прототип нужно запускать в Docker, через `sh`/`bat` и через python-ядро Pterodactyl — единый Python-рантайм закрывает все три сценария без компиляции. Архитектура (REST + WS + JSON-документы) позволяет позже переписать горячие места на Rust без смены фронтенда и схемы БД.

## Быстрый старт

### 1. Одной командой (Docker с MySQL, либо Python — что найдётся)
```bash
curl -fsSL https://raw.githubusercontent.com/amper24/AmperverserDnD-Table/main/install.sh | bash
```
Откроется `http://localhost:8080`. Переменные: `DND_DIR` (папка), `DND_MODE=docker|python`, `PORT`.

### 2. Docker Compose (MySQL + приложение)
```bash
cp .env.example .env      # при желании поправьте SMTP и пароли
docker compose up -d --build
```

### 3. Linux / macOS / Pterodactyl (python egg)
```bash
./run.sh
```
Скрипт сам создаёт venv, ставит зависимости, при отсутствии `.env` использует SQLite (`data/dnd.db`). Порт берётся из `PORT` или `SERVER_PORT` (Pterodactyl).

**Pterodactyl:** импортируйте `deploy/pterodactyl-egg.json` (Admin → Nests → Import Egg), создайте сервер, укажите `DATABASE_URL` (например, MySQL из панели) и запускайте. Startup-команда — `bash run.sh`.

### 4. Windows
Установите Python 3.10+ (галочка *Add to PATH*) и запустите `run.bat`.

## Настройка (`.env`)
| Переменная | Описание |
|---|---|
| `DATABASE_URL` | `mysql+aiomysql://user:pass@host:3306/db` или `sqlite+aiosqlite:///./data/dnd.db` |
| `PORT`, `HOST` | порт/адрес (по умолчанию 8080 / 0.0.0.0) |
| `SMTP_HOST/PORT/USER/PASSWORD/FROM` | почта для кодов входа. Если `SMTP_HOST` пуст — код печатается в консоль сервера |
| `DEV_SHOW_CODE` | `true` — код также возвращается в ответе API и подставляется в форму (только для разработки!) |

## Авторизация
Вход по одноразовому 6-значному коду на почту (10 минут, 5 попыток). Сессия — httpOnly cookie на 30 дней. В модели пользователя уже есть поле `google_sub` — вход через Google добавится отдельным роутером без миграций.

## Как пользоваться
1. Войдите, создайте кампанию — вы её **мастер**.
2. ⚙ *Настройки* → создайте ссылку-приглашение (для игроков или для второго мастера) и отправьте её.
3. 🖼 *Ассеты*: перетащите свои картинки (карты, токены) — они сжимаются в WebP + deflate и хранятся в БД в base64; браузер распаковывает их сам (`DecompressionStream`). Есть набор встроенных токенов/объектов/карт.
4. Перетаскивайте ассеты на стол. Слой карты — через выпадающий список «Слой» вверху.
5. 🧙 *Персонажи*: создайте лист, перетащите персонажа на стол — появится токен, связанный с листом (двойной клик по токену открывает лист поверх стола; кнопка ⧉ — в отдельном окне).
6. 📚 *Справочник*: перетаскивайте расы/классы/предметы/заклинания прямо на лист персонажа; монстров — на стол (создаётся токен с хитами и статблоком). Мастер может добавлять свои записи (homebrew).
7. Инструменты стола: выбор (V), панорама (H / пробел / ПКМ), линейка (R, видят все), рисование (D), текст, указка (P), туман войны (F, только мастер). Delete — удалить, стрелки — сдвиг на клетку, Ctrl+C/V — копия.
8. 💬 Чат: `/r 2d20kh1+5`, кнопки кубиков, скрытые броски мастера. ⚔ Инициатива: «Собрать со стола».
9. Мастер переключает сцены и кнопкой «👁 Показать» назначает активную сцену игрокам.

## Структура
```
app/
  main.py         # FastAPI, роутеры, отдача статики
  config.py       # настройки из .env
  db.py models.py # SQLAlchemy (MySQL/SQLite)
  auth.py         # коды на почту, сессии
  realtime.py     # WebSocket-хаб: стол, чат, броски, права игрок/мастер
  images.py       # сжатие изображений -> zlib -> base64
  seed.py seed_data.py  # базовый справочник SRD (рус.) и встроенные ассеты
  routers/        # campaigns, scenes, assets, characters, compendium
  static/         # index.html, app.js (лобби+кампания), table.js (canvas-стол), sheet.js (лист), compendium.js
deploy/pterodactyl-egg.json
run.sh run.bat install.sh Dockerfile docker-compose.yml
```

## Права
- **Мастер**: всё. Скрытые элементы, туман, слои, сцены, приглашения, роли, homebrew.
- **Игрок**: видит активную сцену без скрытых элементов; двигает только свои токены (владелец назначается мастером или создаётся при перетаскивании своего персонажа); рисует, измеряет, пишет в чат; редактирует своих персонажей.
