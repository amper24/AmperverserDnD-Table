# Повышение уровня

Кнопка «▲ Повысить» рядом с полем «Уровень» на листе персонажа открывает мастер
`static/levelup.js` (окно в стиле D&D Beyond: слева шаги, справа выбор, внизу «Назад / Далее»).
Мастер меняет лист на месте и сохраняет его обычным автосохранением; отмена ничего не меняет.

## Откуда берутся данные

- **Запись класса справочника** (редакция листа): `features` (умения по уровням), `feature_texts`,
  `subclasses[].features` (умения подклассов), `hit_die`, `spellcasting`. Класс ищется по названию на листе
  (`sheet.class`), для своих классов — по названию в справочнике; если найти не удалось, мастер предложит выбрать класс.
- **Таблицы развития** `static/class-progression.js` — бонус мастерства, заговоры, известные и подготовленные
  заклинания, ячейки, магия договора и столбцы классов («Ярости», «Скрытая атака», «Очки ки»…). Файл генерируется
  `python3 tools/srd/build_progression.py --src …/OmnisGM-Rules/src/dnd` из таблиц SRD 5.1 (редакция 2014) и 5.2 (2024),
  CC BY 4.0. У записи класса может быть собственное поле `progression` того же вида — оно важнее таблицы.

## Классы листа

Лист хранит классы в `sheet.classes = [{name, level, subclass, hit_die}]`; `sheet.level` — общий уровень, `sheet.class` и
`sheet.subclass` — строки для показа («Волшебник 3 / Воин 1»). У старых листов `classes` нет: класс берётся из
`sheet.class`, уровень — из `sheet.level`. Если общий уровень в шапке правили вручную, разница уходит в первый класс.
Бонус мастерства считается по общему уровню, кость хитов — по классу (`hit_dice` вида `3d6+1d10`).

## Шаги

| Шаг | Когда | Что делает |
|---|---|---|
| Класс | всегда | какой из ваших классов повысить, либо новый класс (мультикласс) с проверкой требований 13 в основных характеристиках; флажок «Игнорировать требования» — для решений мастера |
| Обзор | всегда | что меняется (мастерство, кость хитов, ячейки, столбцы класса), новые умения с описаниями |
| Здоровье | всегда | среднее, бросок или своё значение + мод. Телосложения (минимум 1); при росте Телосложения — пересчёт прошлых уровней |
| Подкласс | у класса нет подкласса, уровень ≥ первого уровня умений подклассов | карточки подклассов; умения выбранного добавляются сразу |
| Навык | новый класс: бард, следопыт, плут | один навык (бард — любой, остальные — из списка класса) |
| Характеристики | в умениях уровня есть «Увеличение характеристик» | +2 к одной или +1/+1 к двум (максимум 20) либо черта из справочника |
| Эпический дар | «Эпическое благо / Эпический дар» (2024) | выбор «Дара …» |
| Компетентность | «Компетентность / Экспертиза» | два навыка из тех, где уже есть владение |
| Варианты | боевой стиль, метамагия, воззвания и дар договора колдуна, избранный враг и природный исследователь следопыта | выбор нужного числа вариантов; в воззваниях — необязательная замена одного известного; в 2024 боевой стиль — это черта |
| Заклинания | у уровня появляются заговоры или заклинания | выбор из списка класса с фильтром по кругу; замена одного известного (у классов с «известными» заклинаниями); «Тайны магии» барда — заклинания любых классов |
| Итог | всегда | сводка и подтверждение |

После подтверждения мастер сразу закрывается и возвращает на страницу персонажа: хиты, умения и заклинания уже
обновлены, книга показывает запись «Уровень повышен: N — вернулись на лист персонажа». Чтобы повысить следующий
уровень, нажмите «▲ Повысить» ещё раз.

Применение: уровень, бонус мастерства, максимум и текущие хиты, кость хитов, характеристики, умения класса и подкласса
(в `sheet.features`, механика подтягивается из `mechanics` класса), выбранные варианты умений, компетентность,
ячейки заклинаний, новые заклинания в `sheet.spells.known`. Запись о повышении добавляется в `sheet.level_log`
(последние 40) и видна на вкладке «Умения».

Из умений уровня исключаются перечни вариантов: в записях класса «Боевой стиль», «Метамагия» или «Таинственные воззвания»
перечислены вместе со всеми вариантами, а на лист попадают только выбранные.

## Мультиклассирование

- Новый класс добавляется с 1-го уровня: умения этого уровня, владения из таблицы SRD (записываются умением «Владения
  мультикласса» и строкой в «Владения и языки»), спасброски и стартовое снаряжение не выдаются.
- Ячейки заклинаний: один заклинательный класс — по его таблице; два и больше — по таблице волшебника для суммарного
  уровня заклинателя (полный заклинатель — уровень, паладин и следопыт — половина: 2014 с округлением вниз, 2024 вверх,
  Мистический рыцарь и Мастер иллюзий — треть). Ячейки магии договора колдуна добавляются к общим ячейкам того же круга.
- Заговоры, известные и подготовленные заклинания считаются по каждому классу отдельно, по уровню класса.

## Отмена

На вкладке «Умения» → «История повышений» у последней записи есть кнопка «↶ Отменить». Она возвращает уровень, классы,
хиты, характеристики, добавленные умения и заклинания (забытые возвращаются), ячейки и навыки; прочие правки листа
сохраняются. Отмена доступна только для последнего повышения и пока общий уровень листа не менялся вручную.

## Ограничения

- Характеристика заклинаний на листе одна (`spells.ability`): у мультикласса из нескольких заклинателей она берётся от первого.
- Варианты умений без списка в данных (воззвания и метамагия 2024, мастерство оружия, тактическое мастерство) помечены
  «Вручную» — вариант добавляется из справочника.
- Классы с подготовкой заклинаний (жрец, друид, паладин 2014, волшебник) готовят заклинания на отдыхе — мастер только показывает число.
- Повышать можно по одному уровню за раз: после подтверждения мастер закрывается, следующий уровень — новая кнопка
  «▲ Повысить» на листе.
- Умения, которые не складываются при мультиклассировании (Дополнительная атака, Защита без доспехов), не проверяются.

## Оформление
Акцент окна берётся из цвета класса (`CLASS_COLOR` в `static/levelup.js`), цвета школ магии — `SCHOOL_COLOR`. Тексты умений и подклассов выводятся функцией `rich`: абзацы, маркированные списки и таблицы (`|`-строки). Стили — блок `.lu-*` в `static/style.css`; на экранах уже 860 px степпер уходит в верхнюю полосу, карточки в одну колонку.
