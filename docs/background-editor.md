# Редактор предыстории

Отдельный конструктор предыстории по образу редакторов класса и расы:
**Справочник → Предыстории → «+ Создать свою запись»** или **«Редактор предыстории»
в карточке предыстории**. Код — `static/background-editor.js`
(`window.BackgroundEditor`), стили — те же `.ced-*`, что у остальных редакторов.

## Разделы

| Раздел | Что правится |
|---|---|
| **Общее** | название (ru/en), редакция, описание |
| **Навыки** | владения навыками (запись «Навыки» можно перетащить из справочника) и выбор игрока: сколько и из каких навыков |
| **Владения** | инструменты предыстории |
| **Языки** | языки списком, «языков на выбор» числом и примечание для листа |
| **Снаряжение** | текст стартового снаряжения формата SRD — его разбирает мастер создания |
| **Способности** | умение предыстории (название и текст), черта 2024 (`data.feat`) и характеристики на выбор 2024 (`data.asi_options`) |
| **Характер** | черты характера, идеалы, привязанности и слабости — таблицы для отыгрыша (2014) |

## Узлы графа и поля записи

Мастер создания читает предысторию и из графа (`rule.*`), и из сырых полей,
поэтому редактор пишет в оба места:

| Что | Узел | Поле записи |
|---|---|---|
| владение навыком | `rule.list` (kind `skill_proficiency`, id `bg_skills`) | `data.skills` |
| выбор навыков игроком | `rule.list` (kind `skills`, id `bg_skills_choice`, count, options) | `data.skills_choice { count, from }` |
| инструменты | `rule.list` (kind `proficiencies`, label «Инструменты») | `data.tools` |
| языки | `rule.list` (kind `languages`) | `data.languages` — список, число («любые два языка») или примечание |
| умение предыстории | `rule.list` (kind `feature`) | `data.feature` / `data.feature_text` |
| черта 2024 | — | `data.feat` |
| характеристики на выбор 2024 | — | `data.asi_options` (СИЛ, ЛОВ, …) |
| стартовое снаряжение | — | `data.equipment` |

Узлы обновляются **на месте**: id и связи (например, условие редакции) сохраняются;
когда значений нет, узел удаляется, а не остаётся заготовкой. Неизвестные редактору
поля записи сохраняются как есть.

## Как это видят мастер создания и лист

- `data.skills` и узел `rule.list` (kind `skill_proficiency`) → владения навыками (проекция графа);
- узел `rule.list` (kind `skills`) → выбор навыков: значения приходят ключом `bg_skills_choice`
  через `ruleChoices` (своя предыстория может спрашивать выбор, как раса или класс);
- узел `rule.list` (kind `feature`) → умение отдельной карточкой; `data.feat` → модуль черты с
  пометкой предыстории (`backgroundFeatModule`), а если записи черты нет —
  напоминание текстом;
- `data.equipment` → стартовое снаряжение (парсер снаряжения мастера создания);
- `data.languages` → строка «Языки предыстории» на листе.

Регрессия — `tests/background-editor.test.cjs`: круг чтения и записи, пустая запись,
проекция правок в лист и поля записей SRD 2024.
