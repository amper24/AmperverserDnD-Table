## Как проверять числа в документации

`tests/docs-numbers.test.cjs` сверяет счётчики в README/CHANGELOG/этих документах с реальными
dанными: число типов узлов, шаблонов и стартёров, записей SRD, индексов в `src/store/db.rs`,
предупреждений integrity и счётчики тестов. Если добавляете тест или узел — обновите и числа в доках,
иначе `node --test tests/docs-numbers.test.cjs` упадёт.
