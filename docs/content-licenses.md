# Наборы правил D&D и лицензии

## Рекомендация для «классики» D&D 5e

Для официального контента пятой редакции стоит держать отдельные наборы по редакциям, не смешивая их в один список:

1. **D&D 5e (2014) — SRD 5.1.** Официальный открытый набор правил. Wizards of the Coast выпустила SRD 5.1 по **CC BY 4.0** (он также исторически доступен по OGL 1.0a). Для продукта предпочтительнее CC BY 4.0: она допускает копирование и адаптацию, в том числе коммерческое использование, при указании авторства, ссылки на лицензию и отметке изменений.
2. **D&D 5e (2024) — SRD 5.2.1.** Отдельный набор для обновлённых правил 2024 года; также распространяется по **CC BY 4.0**. Хранить отдельным набором, потому что классы, термины и правила двух редакций не всегда взаимозаменяемы.

В приложении уже есть локальные базы SRD 2014 и SRD 2024. Они являются открытой частью правил, а не полными Player’s Handbook, Dungeon Master’s Guide и Monster Manual. При дальнейшем расширении нужно сохранять происхождение и редакцию каждой записи и не выдавать SRD за полный каталог D&D.

### Атрибуция

Для распространения адаптированных данных добавлять к набору (или к общему экрану лицензий) атрибуцию соответствующего SRD. Минимальный вариант:

> This work includes material taken from the System Reference Document 5.1 ("SRD 5.1") by Wizards of the Coast LLC and available at https://dnd.wizards.com/resources/systems-reference-document. The SRD 5.1 is licensed under the Creative Commons Attribution 4.0 International License available at https://creativecommons.org/licenses/by/4.0/legalcode. This work includes changes to the original material.

Для редакции 2024 использовать отдельную формулировку SRD 5.2.1 и официальный адрес https://www.dndbeyond.com/srd. В атрибуции указывать фактические преобразования/перевод/сокращения, если они есть. CC BY не даёт права использовать товарные знаки или подразумевать одобрение Wizards.

## Что не включать автоматически

- Полные тексты Player’s Handbook, Dungeon Master’s Guide, Monster Manual, их не-SRD подклассы, заклинания, монстров и предметы защищены авторским правом, если для конкретного материала не указана отдельная открытая лицензия. Бесплатный просмотр на сайте или наличие текста на стороннем сайте сами по себе не дают права копировать его в публичную базу.
- Материалы DnD.su нельзя считать открытыми только на основании доступности сайта. Этот ресурс не использовался как источник для локальных seed-данных; копировать его подборки, переводы или производные от книг без разрешения не следует.
- «Basic Rules» и прочие бесплатные для игроков ресурсы не следует импортировать целиком без проверки условий именно на перераспространение. Доступность для игры не равна лицензии на включение в приложение.

## Дополнительные наборы

- Дополнительные материалы сторонних авторов подключать **по каждому продукту отдельно** — только если сам автор явно разрешил распространение и адаптацию (например, CC BY 4.0 или ORC). Сохранять название автора, URL, лицензию, обязательную атрибуцию и редакцию; при сомнениях держать набор приватным/локальным.
- **OGL 1.0a** допустима только для материала, прямо опубликованного под этой лицензией, с выполнением её требований (включая требуемый текст лицензии и обозначение Open Game Content/Product Identity). Это отдельный режим с большей юридической и упаковочной нагрузкой; не переносить в него автоматически материал SRD 5.1, который можно использовать по CC BY 4.0.
- **D&D 3.5 SRD/OGL** не является хорошим базовым дополнением для текущего 5e-листа: это иная редакция со своими терминами и механикой. Если добавлять её позднее, оформлять как отдельную систему, а не смешивать с 5e.
- ORC-наборы других систем (например, Pathfinder) не являются контентом D&D только из-за открытой лицензии. Не добавлять их в D&D-каталог без явно отдельного режима/системы.

## Практическое правило

Набор правил должен иметь проверяемый источник и лицензию на распространение. В мастерской лицензию можно выбрать из списка (CC BY/CC BY-SA/CC0, MIT, Apache-2.0, BSD, GPL, OGL 1.0a, ORC, All rights reserved) или вписать свою; отдельно хранятся URL источника и атрибуция. Перед публикацией сервер требует лицензию и атрибуцию (кроме CC0), а владелец подтверждает право публикации. Лицензия All rights reserved оставляет набор приватным и закрывает экспорт/клонирование для других пользователей; лицензии на ПО вроде MIT обычно не подходят для текста правил. Эти поля сохраняются при экспорте, импорте и клонировании. Кампания включает только нужные ей наборы; отключение набора не стирает сохранённые снимки данных из листов персонажей. Если лист использует pack-записи, интерфейс сообщает об отключённых наборах и мастер может подключить их к кампании.
